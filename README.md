# AI Economic Agent Evaluation

A reproducible evaluation framework for measuring the accuracy, consistency, and reliability of AI agents on economic and business reasoning tasks.

## Goal
Evaluate whether an AI agent produces economically correct, quantitatively accurate, causally sound, and consistent decisions.

## Benchmark Areas
- Economic reasoning
- Business decision-making
- Quantitative accuracy
- Causal reasoning
- Experimentation
- Consistency and unsupported claims

All benchmark cases and outputs in this portfolio project are synthetic.
